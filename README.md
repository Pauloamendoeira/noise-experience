# NOISE Experience MVP

Pacote pronto para publicação estática.

## Arquivos
- `index.html` — jogo completo e jogável

## GitHub Pages
1. Crie um repositório novo.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em "Build and deployment", escolha "Deploy from a branch".
5. Selecione a branch `main` e a pasta `/root`.
6. Salve e aguarde a URL pública.

## Netlify
Arraste a pasta inteira ou este ZIP para o Netlify Drop.

## Vercel
Importe o repositório ou faça upload do projeto estático.

Não há dependências externas nem processo de build.
